# herbie-f1

A 3D Formula One racing game in the browser (three.js + TypeScript + Vite). Pick one of 11 real circuits, a 2022 team and driver, a difficulty and race length, and race the full 20-car grid.

## Play

```fish
npm install
npm run dev
```

Open the printed URL: **Quick race** → track → car → driver → settings.

**Career**: create a 17-year-old rookie (name, number, difficulty, race length), pick a first team and race an 11-round season. Points follow F1 rules; finish high enough in the championship and bigger teams offer you a seat for next season. Progress is saved in the browser.

Cutscenes: race intro, pit stops (full crew, jacks, wheel guns, release light, live stationary time), podium, contract signings (tap or Enter to skip).

Difficulty: Beginner and Amateur add auto-braking, steering help and extra grip; Semi-Pro auto-brakes; Pro and up give no help.

| Key | Action |
| --- | --- |
| ↑ / W | Throttle |
| ↓ / S / Space | Brake, reverse when stopped |
| ← → / A D | Steer |
| C | Chase / cockpit / TV camera |
| R | Put the car back on the track |
| M | Mute engine |
| B | Box: pit at the end of this lap for new tyres |

Gamepads work too (left stick, RT throttle, LT brake). On an iPad or phone, on-screen ◀ ▶ / GAS / BRAKE buttons appear; tap to start.

URL options: `?size=10&countdown=0` (`size` trims the field).

## Code

| File | What |
| --- | --- |
| `src/track.ts` | Centreline geometry, projection onto the track |
| `src/circuits.ts` | Circuit centrelines, generated by `scripts/import-circuits.mjs` from [bacinger/f1-circuits](https://github.com/bacinger/f1-circuits) (MIT) |
| `src/grid.ts` | 2022 teams and drivers, car pace and driver skill |
| `src/car.ts` | Car physics: power, drag, downforce grip, braking, steering |
| `src/ai.ts` | Speed profile and pure-pursuit AI drivers |
| `src/race.ts` | Grid, countdown, laps, collisions, barriers, standings |
| `src/scene.ts` | Track, scenery and car meshes |
| `src/career.ts` | Career rules: calendar, points, championship, contract offers |
| `src/people.ts` | Animated people: pit crew, podium, the player's driver |
| `src/ik.ts` | Arm solver that keeps the driver's hands on the wheel |
| `src/main.ts` | Menus, cutscenes, render loop, input, camera, HUD, engine sound |

Simulation code has no three.js dependency, so it runs headless in tests.
